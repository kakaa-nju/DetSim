## 保存态表达式复用的前提

审查发现`traceeN(...)`可跨节点读取，结果不能只按当前node的ts_hash和表达式缓存。
还依赖每节点可执行文件、全局DWARF/ELF上下文、store生命周期。live读必须保持新鲜。
缓存丢失/淘汰必须回到原求值器，不能拿实时内存或假值代替缺失保存数据。

已加入dwarf_symbol_generation：初始化/失败、清理、ELF装载和实际懒惰类型/大小/
成员缓存写入均改变epoch；稳定命中不改变。它不让原有串行符号服务变成线程安全。
同时修复了旧问题：dwarf_cleanup之后的负大小缓存，在dbg为空时可穿过dwarf_init，
使真实类型仍被报告为0。初始化现在统一清理，legacy cleanup也走同一实现。

独立旧实现负例失败、新实现通过；根任务用/usr/bin/g++14复核check-dwarf和
check-state-view。辅助会话误用PATH中的另一g++失败不代表/usr/bin工具链不可用；
正式基线和根任务仍使用/usr/bin/g++14，未改变系统工具链。

已通过：NP3生产构建、check-dwarf、check-state-view、40个native场景；有限BFS和
违规BFS新增回执断言，中断Raft实跑核对转换数；修正后的perf smoke通过。

## 保存态求值缓存候选已实现（默认关闭）

新增 `DETSIM_OBSERVATION_CACHE=off|on|verify`，默认off。模式在saved StateView
构造时读取，副本保留模式；live view始终走原来的live读取。成功表达式的实际
read/require_symbols依赖被记录，仅接纳本节点且至少有一次保存态内存读取的结果。
跨节点读取、仅跨节点的符号检查、不执行的条件分支、异常路径均有独立测试。

缓存按node/root/executable分组，store或symbol epoch变化清空；符号相关命中还会
检查exe兼容性。缓存持有已验证SnapshotView，命中是保留的观察结果，不能冒充
重新检查磁盘完整性。冷缓存/淘汰后缺失保存数据必须报错；verify在当前保留root
上重算。未缓存异常、live内存或没有读保存内存的常量结果。

每控制线程最多16个root，每root256个表达式，表达式长度上限1024、配置exe长度
上限4096、编码root上限64KiB；超限仍正常求值。64KiB不是总内存上限，还包含
解析表、有限page cache与缓存键。所有缓存/统计都是瞬态状态，不进入快照身份。

## Syscall-array encoding candidate (screening only)

The serializer packs each syscall record's actual members into a
fixed byte buffer and performs one cereal binary-data operation for the array.
It preserves the old60-byte x86-64 records, array order and entire archive suffix,
without serializing C++ padding or changing versions/identity. Input is unpacked
only after a complete block read. Individual syscall_info serialization remains.

An independent legacy encoder in tests/identity_integration.cpp passes before
and after the change. It checks all64slots with negative syscall numbers, high
arguments, futex absent/present, full archive bytes, legacy decode/re-encode, and
first/last record and suffix truncations. The futex fixture and thread containers
are empty; this is wire compatibility coverage, not complex-thread behavior.
NP2 identity/capture, NP1 state-I/O, NP3 production build pass. A read-only
independent review found no concrete compatibility defect. The reviewed
record-size calculation now uses actual member sizes; identity passes again.

## Resident page-index reuse candidate

After live authority is invalidated, resident::publish previously rebuilt an
immutable page index even when the newly captured root had identical page
references and mapping geometry. The candidate reuses object_hint.pages only
after opening the new root and checking the full saved geometry/reference list.
PID/store-generation guards and capture/restore checks remain. Genuine rebuilds
reserve page/region vector capacity. No live-memory proof comes from the hint.

index owner. The ownership assertion fails on the old implementation, passes

## Reuse the established restore barrier

The two public low-level restore methods still validate mode and reject active
rseq before opening/mutating the snapshot. Private restore bodies let the
high-level operation reuse its already-completed owned-carrier barrier. The
system operation still verifies every node before modifying any node; the
single-node operation verifies its own node. Between that barrier and restore
completion there is no ordinary guest execution, thread creation/replacement or
rseq registration: only fixed restore syscall injections and the existing
pending-syscall suppression to EXIT are allowed. No global or cross-call
"already checked" flag is introduced.

The NP2 ptrace-count regression fails before the change, then passes with one
rseq probe per physical carrier in the high-level barrier; both public methods
still independently probe. A real rseq registration on the later node rejects
before earlier-node memory/registers/process/time/status/budget/hash/save-count
changes. NP2 capture normal/tiny and NP1 lifecycle full/pages normal/tiny pass,
including active-rseq-worker rejection and pending-clone rollback. Independent
read-only review found no concrete defect; NP3 build and real Raft four
healthy/mutant × full/pages rows with both caches verify and3x replay pass.
The combined tree also passes `make -j4 NP=3 CC=/usr/bin/gcc CXX=/usr/bin/g++ check`.
Logs/plan: build/serial-bfs-1500/restore-barrier-*.
